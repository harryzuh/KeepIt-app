# 1.0.1 — Boas-vindas e navegação para Entrar / Criar conta

**Módulo:** M1 · **Projeto Linear:** 1.1 (acesso), 1.2 (acesso) · **Prioridade:** Alta · **Depende de:** 1.0
**UCs:** UC001, UC002 · **RF:** RF01, RF02 · **RNF:** RNF10, RNF19, RNF24, RNF29, RNF30
**Telas:** 01 Boas-vindas → 02 Entrar / 03 Criar conta
**Camadas:** Front-end (View) · QA

## História
**Como** visitante, **quero** ver uma tela de boas-vindas com as opções de entrar, cadastrar-me e ler os termos **para** começar a usar o KeepIT sem precisar adivinhar o caminho.

## Critérios de aceite
1. **Dado** um visitante sem sessão, **quando** abre a raiz do sistema, **então** vê a tela 01 com os botões Entrar e Cadastrar e o link Termos de uso.
2. **Dado** a tela 01, **quando** clica em Entrar, **então** vai para a tela 02 (UC001).
3. **Dado** a tela 01, **quando** clica em Cadastrar, **então** vai para a tela 03 (UC002).
4. **Dado** um usuário já logado, **quando** abre a raiz, **então** é redirecionado para a tela 05.
5. **Dado** falta de conexão, **quando** o visitante abre qualquer tela pública, **então** vê a mensagem "Sem conexão com a internet" (fluxo de exceção dos UC001/UC002).
6. **Dado** a tela 01 em celular e desktop, **então** os botões têm tamanho de toque adequado, rótulos acessíveis e a interface é compreensível sem treinamento (RNF29).

## Regras de negócio
- Telas públicas não exigem token; nenhuma chamada à API é necessária para exibi-las.
- Usuário deve estar conectado à internet (RNF30).

## Fora do escopo
Landing page institucional (a tela 01 é a entrada do app).
