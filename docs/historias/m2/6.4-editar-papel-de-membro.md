# 6.4 — Editar papel de membro

**Módulo:** M2 · **Projeto Linear:** 6.4, 6.4.1 · **Prioridade:** Importante · **Depende de:** 6.1
**UCs:** UC034, UC036 · **RF:** RF28 · **RNF:** RNF05, RNF11, RNF27, RNF31
**Telas:** 11 Família (menu ⋯) → 22 Gerenciar membro (modal)
**API:** `PATCH /casa/membros/:id` · **Erros:** 403 `SEM_PERMISSAO`, 404 `NAO_ENCONTRADO`, 422 `DADOS_INVALIDOS`, 409 `ESTADO_INVALIDO` (proposto, tentativa sobre o ADMIN/si mesmo)
**Camadas:** Back-end · Front-end · QA · AppSec

## História
**Como** ADMIN, **quero** mudar o papel de um membro entre Editor e Leitor **para** controlar o que cada pessoa pode fazer.

## Critérios de aceite
1. **Dado** o menu ⋯ de um membro, **quando** clico, **então** abre o modal da tela 22 com nome, e-mail, o papel atual selecionado e as opções Editor e Leitor com descrição.
2. **Dado** que escolho outro papel e clico em "Salvar papel", **então** o papel é atualizado, o modal fecha e a lista reflete a mudança.
3. **Dado** que não altero a seleção, **então** "Salvar papel" fica desabilitado.
4. **Dado** o papel alterado, **então** a nova permissão vale na próxima requisição do membro, sem exigir novo login (a API consulta o papel atual, Q6).
5. **Dado** papel ADMIN ou inválido no corpo, **então** 422 `DADOS_INVALIDOS`.
6. **Dado** que o id é do próprio ADMIN, **então** a API recusa (o ADMIN não altera o próprio papel); o front nem exibe o menu para ele.
7. **Dado** um id de membro de outra Casa ou inexistente, **então** 404 `NAO_ENCONTRADO` (nunca confirma que existe, RNF31).
8. **Dado** a alteração, **então** o log `MEMBRO_PAPEL_ALTERADO` guarda ADMIN, membro, papel anterior e novo (RNF05).
9. **Dado** matriz de permissões, **então** EDITOR e LEITOR recebem 403 `SEM_PERMISSAO`; sem token 401; ADMIN de outra Casa recebe 404.
10. **Dado** falha de rede ou da API, **então** o modal mostra o erro e mantém o papel anterior.
11. **Dado** que o id da URL não é inteiro, **então** 422 `DADOS_INVALIDOS`.

## Regras de negócio
- Apenas EDITOR ou LEITOR podem ser atribuídos (UC034).
- Editor adiciona, edita e exclui produtos e tags; Leitor só consulta.
